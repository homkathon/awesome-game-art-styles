Style demos

One scene, four renderers. Each demo is a single HTML file using three.js and procedural shapes, with the shader code commented so you can copy it. Part of Awesome Game Art Styles.

  • Toon
    Banded light from a gradient map, inverted-hull outlines.
  • PS1
    Vertex snapping, affine textures, Gouraud light, 15-bit dither.
  • 1-bit
    Bayer 8×8 dither to two colours, depth outlines.
  • Pixelated 3D
    Low-res orthographic render, texel-snapped camera, depth and normal edges.
