## How to spot it

- Top-down pixel art in hot pinks and cyans
- Screen shake and flashing on every hit
- VHS-style grain and colour shift

## Techniques

- palette cycling
- screen shake
- chromatic aberration

## Reference games

- [Hotline Miami](https://store.steampowered.com/app/219150/)

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section. When it runs, put a screenshot of your scene next to the gallery above and compare values first, then palette, then detail.

1. Use a saturated palette and cycle background colours.
1. Add screen shake, hit-stop and chromatic aberration on impacts.
1. Overlay scanlines and a slight VHS colour offset.
