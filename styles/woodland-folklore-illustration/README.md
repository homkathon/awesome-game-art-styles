## How to spot it

- Ornamental plants and mushrooms frame the scene
- Odd but friendly creature silhouettes
- Earthy moss and soil colour palette

## Techniques

- modular plant silhouettes
- layered foliage
- earthy palette

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section. When it runs, put a screenshot of your scene next to the gallery above and compare values first, then palette, then detail.

1. Illustrate separate botanical props and whimsical creature silhouettes with visible pen texture.
1. In Godot, scatter Sprite2D groups in depth layers, reserving empty space around gameplay interactions.
