## How to spot it

- Thick outlines and flat shading on a 3D city
- Graffiti, stickers and posters on every surface
- Clashing saturated colours, chunky type

## Techniques

- toon shading with outlines
- decal-heavy environments
- posterised textures

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section. When it runs, put a screenshot of your scene next to the gallery above and compare values first, then palette, then detail.

1. Start from a toon setup (hard light bands plus outlines) with fully saturated base colours.
1. Cover walls with decals: tags, stickers and posters, drawn as flat vector shapes.
1. Keep textures flat colour; let the graffiti carry all the detail.
