## How to spot it

- Large character portraits in pixel art
- Neon accents on dark purples and blues
- Interface frames like old PC games

## Techniques

- portrait-heavy layouts
- limited palette with neon accents

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section. When it runs, put a screenshot of your scene next to the gallery above and compare values first, then palette, then detail.

1. Make portraits the main visual; keep backgrounds simple.
1. Use a dark base palette with one or two neon accents.
1. Frame the screen with retro UI panels.
