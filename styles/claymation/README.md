## How to spot it

- Surfaces show fingerprints, tool marks and fabric
- Movement steps like stop-motion animation
- Sets look physically built

## Techniques

- photogrammetry of physical models
- stepped animation
- fingerprint normal maps

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section.

1. Sculpt or scan real clay; failing that, add fingerprint and tool-mark normal maps.
1. Animate on twos (12 fps) with constant interpolation.
1. Light like a model set: soft key, visible shadows, shallow depth of field.
