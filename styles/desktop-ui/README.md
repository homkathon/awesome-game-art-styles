## How to spot it

- Windows, cursors, taskbars and dialog boxes are the whole world
- Period UI: Windows 9x/XP, early web, old phones
- Glitches and corrupted screens as storytelling

## Techniques

- recreated period UI kits
- in-game windowing system
- glitch and corruption effects

## Agent notes

Steps a coding agent (or you) can follow to reproduce the look. The [game-art-style skill](../../skills/game-art-style/SKILL.md) reads this section.

1. Pick one era of interface (Windows 98, XP, early smartphones) and copy its rules: bevels, fonts, sounds.
1. Draw your own icons and window chrome; don't ship real operating-system assets or logos.
1. Build a small window manager (drag, focus, close) and let the story arrive through apps.
